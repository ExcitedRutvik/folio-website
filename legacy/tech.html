01 · Frontend

Frontend & interfaces.

Everything the user actually sees. We pick the lightest tool that does the job — Astro for static, Next.js for product, vanilla for editorial.

Frameworks
  • Next.jsFull-stack React. SSR / ISR. Our default for marketing + product surfaces.
  • AstroStatic-first with islands of interactivity. Fastest LCP we ship.
  • ReactFor component-rich SPAs and embedded widgets.
  • Vue 3 · NuxtWhen your team already lives in Vue.
  • SvelteKitMinimal bundle, smooth interactions.
  • RemixServer-first React with proper form semantics.
  • SolidJSFine-grained reactivity for performance-critical UIs.
Type & tooling
  • TypeScriptDefault on every project — strict mode.
  • ViteModern dev server + bundler.
  • ESLint · PrettierHouse style enforced in CI.
Styling & UI
  • Tailwind CSSUtility-first, ships zero unused CSS.
  • Vanilla CSS / ModulesFor brand-led editorial work like this one.
  • shadcn/uiWhen we need composable, accessible primitives.
  • Radix · Headless UIFor complex menus, dialogs, comboboxes.
  • Framer Motion · GSAPProduction-grade motion design.
02 · Backend

Backend & APIs.

Servers, APIs, edge runtimes, background jobs. We're language-agnostic — pick what suits your team, not ours.

Runtimes & frameworks
  • Node.js · HonoEdge-ready, runs anywhere. Default for new APIs.
  • Node.js · FastifyWhen you need raw HTTP throughput.
  • Node.js · NestJSFor larger, structured backends.
  • Python · FastAPIAI-adjacent workloads, typed pydantic models.
  • Python · DjangoAdmin-heavy, batteries-included.
  • Go · Gin / EchoLow-latency services, single binary deploy.
  • PHP · LaravelFor teams in the PHP ecosystem.
APIs & layers
  • REST · OpenAPIThe default — typed via OpenAPI specs.
  • GraphQLWhen clients need flexible aggregation.
  • tRPCEnd-to-end type safety in TS monorepos.
  • WebSockets · SSERealtime feeds, audit dashboards, live previews.
Edge & jobs
  • Cloudflare WorkersSub-50ms cold start, globally distributed.
  • Deno DeployModern JS runtime at the edge.
  • Inngest · Trigger.devBackground jobs, scheduled workflows.

Databases
